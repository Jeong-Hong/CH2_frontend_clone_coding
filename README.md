# CH2 Frontend Clone Coding — 회원가입 페이지

스파르타클럽 회원가입 화면을 HTML과 CSS로 재현한 프론트엔드 클론 코딩 학습 프로젝트입니다. 홍정기의 회원가입 페이지 담당 작업물을 정리했습니다.

> **학습용 정적 UI입니다.** 실제 회원가입, 계정 저장, 휴대폰 인증 등의 백엔드 기능은 포함되어 있지 않습니다. 실제 개인정보나 비밀번호를 입력하지 마세요.

## 프로젝트 소개

- **제작자:** 홍정기
- **주제:** 회원가입 페이지 클론 코딩
- **목표:** 폼 요소와 CSS를 활용해 입력 영역, 선택 버튼, 약관 동의 영역 및 화면 레이아웃 구현
- **구성:** 별도의 패키지 설치나 빌드 과정이 없는 정적 웹 페이지

## 사용 기술

| 기술 | 활용 |
| --- | --- |
| HTML5 | 회원가입 폼, 입력 필드, 라디오 버튼, 체크박스 |
| CSS3 | 카드 레이아웃, Flexbox, 입력 영역 스타일 및 선택 상태 표현 |
| JavaScript | 닫기 버튼의 이전 페이지 이동을 위한 인라인 이벤트 |
| Pretendard | CDN으로 불러오는 웹 폰트 |
| XEIcon | CDN으로 불러오는 닫기 아이콘 |

## 구현 내용

### 회원가입 입력 화면

- 이메일, 비밀번호 및 비밀번호 확인 입력란
- 이름, 국가번호, 휴대폰 번호 및 인증번호 입력란
- 생년월일 입력란
- 남성 / 여자 / 선택안함 라디오 버튼
- 필수·선택 약관 동의 체크박스
- 전체 약관 동의 체크박스와 가입하기 버튼

### 화면 스타일

- 중앙 정렬된 흰색 카드와 연한 회색 배경
- 입력 영역의 둥근 모서리와 구분선
- 성별 선택 시 배경색·글자색 변경
- 체크 상태에 따른 약관 아이콘 이미지 변경
- 서비스 로고와 빨간색 가입 버튼

## 실행 방법

### VS Code Live Server 사용

1. 이 저장소를 복제하고 VS Code에서 엽니다.

   ```bash
   git clone https://github.com/Jeong-Hong/CH2_frontend_clone_coding.git
   cd CH2_frontend_clone_coding
   code .
   ```

2. VS Code에서 **Live Server** 확장을 설치합니다.
3. `발표/sign_up.html`을 우클릭하고 **Open with Live Server**를 선택합니다.

### Python 로컬 서버 사용

Python이 설치되어 있다면 저장소 최상위 폴더에서 실행합니다.

```bash
python -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8000/발표/sign_up.html`에 접속합니다. 환경에 따라 `python` 대신 `python3` 또는 `py` 명령을 사용하세요.

> 웹 폰트와 아이콘은 외부 CDN에 의존하므로 정상 표시에는 인터넷 연결이 필요합니다. HTML 파일을 직접 여는 것보다 HTTP 로컬 서버 실행을 권장합니다.

## 확인할 동작

- 입력란에 텍스트를 입력할 수 있습니다.
- 성별은 한 번에 하나만 선택되며, 선택된 버튼의 스타일이 바뀝니다.
- 각 약관 체크박스는 라벨을 클릭해 개별적으로 선택·해제할 수 있습니다.
- 전체 약관 동의 체크박스도 자체 선택 상태에 따라 아이콘이 바뀝니다.

## 현재 구현 범위와 제한 사항

| 항목 | 현재 상태 |
| --- | --- |
| 회원가입 화면 및 폼 스타일 | 구현 |
| 성별 선택 및 체크박스 선택 상태 표현 | 구현 |
| 전체 동의와 개별 약관의 동기화 | 미구현 — 현재 서로 독립적으로 동작 |
| 이메일 형식·비밀번호 규칙·비밀번호 일치 검사 | 미구현 — 안내 문구만 표시 |
| 필수 약관 동의 검사 | 미구현 — `required` 클래스는 있으나 제출 검증은 없음 |
| 휴대폰 인증번호 발송 및 검증 | 미구현 — 입력 화면만 제공 |
| 약관 상세 페이지 | 미구현 — `#` 링크 사용 |
| 실제 회원가입 및 데이터 저장 | 미구현 — 폼은 `method="post" action="#"`로 설정 |
| 모바일 반응형 레이아웃 | 개선 필요 — 메인 카드 폭이 `408px`로 고정 |

`가입하기` 버튼은 실제 회원가입을 처리하지 않습니다. 정적 서버에는 POST 처리 기능이 없으므로 제출 시 오류가 발생할 수 있습니다.

닫기 버튼은 브라우저 방문 기록이 있으면 이전 페이지로 이동합니다. 방문 기록이 없을 때는 팀 프로젝트의 `../../_1_강성수_메인페이지/project/sparta_main.html`로 이동하도록 작성되어 있으나, 해당 메인 페이지는 이 저장소에 포함되어 있지 않습니다.

## 학습 포인트

- HTML 폼 요소의 기본 동작과 `name`, `type`, `value` 속성
- `input`과 `label` 연결을 이용한 사용자 선택 처리
- CSS `:checked`와 인접 형제 선택자(`+`)를 활용한 상태 표현
- Flexbox 기반 요소 정렬과 간격 조절
- 상대 경로를 통한 스타일시트·이미지 연결
- 화면 구현과 실제 서비스 기능 구현의 차이

## 향후 개선 방향

- JavaScript로 전체 약관 동의와 개별 약관 상태 연동
- 입력값 유효성 검사 및 오류 메시지 제공
- 화면 크기에 대응하는 반응형 스타일 적용
- 폼 레이블, 이미지 대체 텍스트 및 키보드 접근성 개선
- 독립 실행에 맞는 닫기 버튼 이동 경로 정리

## 참고 및 유의 사항

스파르타클럽 화면을 참고한 비상업적 학습용 프로젝트이며, 실제 서비스 또는 공식 사이트가 아닙니다. 사용된 로고·이미지·디자인의 권리는 각 권리자에게 있습니다.
